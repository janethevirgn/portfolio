Real Growth Story

Struggling in IT... To Thriving Developer

When I first entered the BSIT program at CCDI Legazpi, coding felt like trying to decipher an alien language. I struggled deeply with understanding complex syntax, debugging obscure PHP errors, and wrapping my head around relational databases and network routing. There were countless nights spent doubting whether I belonged in IT.

However, giving up wasn't an option. Taking inspiration from my favorite anime characters, like Rock Lee's unyielding work ethic and Bakugo's relentless drive to excel, I turned my struggles into fuel. I spent endless hours practicing code line-by-line, watching tutorials, seeking guidance from my professor Mr. Jay Millena, and building real projects from scratch.

"Hard work beats natural talent when talent doesn't work hard. Today, I don't just write code. I build AI-assisted spatial systems like ProtCo and engineer full-stack web applications with confidence!"
